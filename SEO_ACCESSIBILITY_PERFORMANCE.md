# SEO, Accessibility, and Performance

## SEO
Unique page titles/descriptions; canonical URLs; Open Graph metadata; sitemap and robots rules. Use structured data only when factual and valid. Do not label the site official. Add dates and source links to editorial pages.

## Accessibility
Semantic landmarks and headings, keyboard controls, visible focus, adequate contrast, factual alt text, reduced-motion support, and no autoplaying sound.

## Performance
Responsive images with dimensions, lazy-load below-the-fold media, avoid unnecessary scripts, and use text/abstract design if verified rights-cleared imagery is unavailable.

## Image integrity
Every asset must pass the manifest approval gate. No unrelated stock photos or AI-generated lookalikes.
