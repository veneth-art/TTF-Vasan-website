# AI Builder — Staged Build Steps

## 1. Inspect
Inspect the repository and identify framework/scripts. Summarize assumptions and proposed changes before editing.

## 2. Foundation
Set up design tokens, typography, responsive layout, navigation, footer, unofficial disclaimer, focus states, and a text-first hero.

## 3. Pages
Build Home, Videos, Biography, News, About, and Privacy with reusable components. Clearly label sample/unverified content.

## 4. Content model
Separate data from presentation. Include source links, review status, dates, and deduplication. Never invent facts.

## 5. Image approval gate
For every photo: verify the person is TTF Vasan; verify any bike represented as his; confirm usage rights; complete the manifest. If any item is uncertain, do not publish it. Use abstract/text-led visuals instead.

## 6. QA
Run available lint/type-check/build commands. Test responsive layouts, keyboard use, reduced motion, external links, and empty states. Check every image against the manifest.

## 7. Handoff
Provide setup/deployment instructions and an honest QA report. List remaining unverified items; do not claim checks that were not run.
