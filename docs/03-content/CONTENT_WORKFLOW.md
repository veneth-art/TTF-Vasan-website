# Content Workflow

1. Discover updates from reliable public sources and permitted feeds/APIs.
2. Capture title, source URL, date, and short factual note.
3. Deduplicate by normalized URL or stable key.
4. Verify claims against the original source and a second reliable source where needed.
5. Write an original summary; do not copy large passages.
6. Complete `docs/02-design/IMAGE_ASSET_MANIFEST.md` before publishing any image.
7. Verify every photographed person is TTF Vasan using reliable source evidence.
8. Verify the specific motorcycle before describing it as one he uses/has used.
9. Confirm usage rights, permission, licensing, or permitted embed/link status.
10. Obtain human review and publish with direct source links.

Hard stops: no generic substitutes, no AI lookalikes presented as real, no unsupported bike claims, no unauthorized reuploads. If uncertain, do not publish the image.
