# Project Brief — TTF Vasan Unofficial Fan Hub

## Purpose
A premium editorial fan website presenting sourced biography details, news, and video links as a portfolio-quality web design project.

## Pages
Home, Videos, Biography, News, About, Privacy.

## Visual direction
Dark motorcycle-inspired editorial design. Obsidian `#09090B`, charcoal `#17171C`, racing red `#F04444`, off-white `#F5F5F5`, muted grey `#A1A1AA`. Space Grotesk headings and Inter body.

## Mandatory imagery requirements
- Every person in a photograph must be TTF Vasan himself, verified using a reliable source.
- Any bike presented as one he uses/has used requires reliable evidence for that specific bike.
- No generic riders, unrelated people, stock models, random bikes, or AI-generated likenesses.
- Use only permission-cleared media or embeds/links allowed by the source.
- If no image qualifies, use text-led design and abstract graphics instead.
- Track every image in `IMAGE_ASSET_MANIFEST.md`.

## Editorial standards
Use reliable sources, original summaries, direct source links, and accurate dates. Mark unverified submissions pending review. Never invent facts or imply official affiliation.

## Success criteria
Responsive, accessible pages; clear fan-made disclaimer; no unsupported facts; complete image provenance; rights cleared; no generic or lookalike imagery.
